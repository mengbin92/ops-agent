# A2A 形态的可选依赖（`opsagent a2a ...` 才需要）。
#
# 主内核（REPL / 单发 / RPC / MCP / 巡检 / 调度 / 通知）不依赖本文件里的任何包，
# 服务器上只跑巡检时无需安装。
#
#   python3 -m pip install -r requirements-a2a.txt
#
# 版本说明：a2a-sdk 1.x 是 protobuf 消息 + PascalCase 方法名（SendMessage / GetTask），
# 与 0.3 时代的 `message/send` 不兼容；协议版本号走 A2A-Version: 1.0 请求头。
#
# starlette 版本不是随手写的：sse-starlette 3.6.0 声明 `starlette>=0.49.1`，
# 低于它会得到 ResolutionImpossible（或更糟——在已有环境里被 pip 破坏性降级成
# “能跑但元数据不成立”的组合）。这组版本已实测装得上并跑通 AgentCard 发布、
# SendMessage、INPUT_REQUIRED 跨请求续跑。
a2a-sdk[http-server]==1.3.0
starlette==0.49.1
sse-starlette==3.6.0
uvicorn==0.34.0
httpx==0.28.1
