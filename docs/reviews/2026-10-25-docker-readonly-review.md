# Docker 只读排查误报修复

日期：2026年10月25日（北京时间）。分支：`develop`，规划已单独提交为 `994b9b2`。

## 根因与修复

| 状态 / 优先级 / 严重度 | 根因 | 修复与覆盖范围 |
| --- | --- | --- |
| ✅ 已修复 / P1 / 高 | shell 分段不识别引用，grep 表达式中的管道符和分号被当成命令边界 | 共享 `_segments` 只按未引用、未转义的实际操作符切段；CLI、Agent、MCP、巡检、快照及 kubectl 作用域判断一起生效 |
| ✅ 已修复 / P1 / 高 | Docker 格式串里的 `=>` 被当成输出重定向，`tee`、`--output` 等数据被当作写标记 | 引用/转义内容按非空白占位保留参数边界；重定向只看实际语法，危险选项按对应命令识别 |
| ✅ 已修复 / P1 / 中 | 所有 `$` 都被当成动态参数，双引号正则末尾锚点误报 | 仅识别实际参数、特殊参数和命令/算术展开；字面量 `$` 放行，动态内容继续要求审批 |
| ✅ 已修复 / P1 / 高 | SSH 外层双引号的本地展开可能被内层单引号掩盖 | 在剥离 SSH 包装前先检查本地展开，拒绝命令替换、变量和反引号执行 |
| ✅ 已修复 / P1 / 高 | 引用重定向目标可能被跳过，特殊空白可能伪装注释或文件名结束 | 保留引用/转义参数的非空白边界；注释与 stderr 重定向只认可 shell 空格、tab 等实际边界 |
| ✅ 已修复 / P2 / 中 | Docker 对象只读别名、批量 inspect 和数字行号查看缺少可识别形状 | 补充对象查询、固定 `xargs ... docker inspect` 和数字行号 `sed -n`，限制额外脚本、参数替换与写子命令 |

固定 `xargs` 只允许可选 `-r`、`-n N` 后调用 `docker inspect` 并追加对象参数，不允许替换 utility 或执行任意脚本。
`sed` 仅接受数字行号的 `p` 脚本与明确文件名，敏感文件读取限制继续生效。
`while`、通用 `awk`/`xargs`、动态变量和命令替换不在此次只读白名单内；批量排查可先列对象，再明确指定名称。
Compose config 的 `-o`、`--output`、`--lock-image-digests` 继续按写操作处理。
