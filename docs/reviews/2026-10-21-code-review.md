## 安全与执行

| 优先级 | 问题与复现场景 | 修复位置及结果 | 不修复的影响 |
| --- | --- | --- | --- |
| P1 | `echo ok` 后接换行或后台 `&` 再执行写命令，整条命令可能判 R0；Unicode 空白和命令前缀也可误命中 | `core.py`、`config.yaml`：补分隔符、限定 shell 空白和完整命令词、完整检查 SSH 内层命令 | 未经审批执行写操作 |
| P1 | `env sh -c ...`、`brew services restart`、`git reflog expire`、日志清理和输出文件选项被白名单放行 | `core.py`、`config.yaml`：收紧动词与写选项；仅豁免 stderr 到 `/dev/null` 或 fd 复制 | 默认只读承诺失效 |
| P1 | 审批哈希压缩引号、转义及 Unicode 空白，导致不同 shell 语义共用授权；坏戳和缺 force 的 R3 戳校验不足 | `core.py`：保留命令语义，核验命令、目标、级别、force 和有限有效期 | 越权复用授权 |
| P1 | `ops_approve` 只检查确认通道是否存在，模型跳过提问也可建戳；用户拒绝后旧戳仍可用 | `agent/tools.py`：工具亲自确认完整命令、目标、级别；非明确批准拒绝并撤销同命令同目标旧戳 | 用户未批准或已拒绝的变更仍可执行 |
| P1 | 独立 `snapshot --cmd` / MCP 快照工具不校验写命令 | `core.py`、`remote.py`：独立和执行前快照统一守门，远程按目标绑定 | 把写操作藏进快照绕过审批 |
| P1 | hook 拒绝文档要求的本仓库 `opsx approve/exec` 包装调用 | `opsx`：仅放行无 shell 展开或外部拼接的本仓库入口；内部继续守门 | 正常审批执行流程不可用 |
| P1 | 本地 shell 超时后子进程继续运行；远程超时被误报为目标进程已停止 | `core.run_shell`：停止本地整个进程组；`remote.py` 明确要求核实远端状态 | 超时后仍继续变更或被错误重试 |
| P1 | 损坏或越界的快照元数据可导致错误恢复；目标变成符号链接后直接覆盖会写入其他文件 | `core.load_snapshot`、本机及远程 rollback：恢复前完整校验；本机写临时文件后原子替换 | 恢复错误文件或破坏原文件 |
| P1 | 流式连接提前结束、错误或 token 截断仍可把未完成工具调用送去执行 | 两个 LLM provider、`agent/loop.py`：完整性及结构校验，异常统一为 LLMError | 执行不完整或错误的指令 |
| P1 | RPC 非对象输入可杀死读线程；未知响应可缓存；EOF 不唤醒等待确认 | `agent/rpc.py`：验证请求，只接收在途响应，断线或错误立即拒绝确认 | 进程挂死或错误授权 |

## 正确性与可靠性

| 优先级 | 问题与复现场景 | 修复位置及结果 | 不修复的影响 |
| --- | --- | --- | --- |
| P2 | `force: "false"` 被转成 True，布尔 TTL、错误数组及嵌套参数未检查 | `core.validate_arguments`、MCP、工具分发：复用现有 schema 校验，移除强制类型转换 | 误发 R3 戳或出现内部异常 |
| P2 | 快照抓取默认同名输出相互覆盖；独立快照失败留下残片且未执行保留策略 | 本机与远程快照：唯一输出名、失败清理、统一保留策略 | 回滚证据丢失或磁盘持续增长 |
| P2 | 多线程或多进程审计轮转与写入竞争 | `core.audit`：文件锁覆盖轮转和追加 | 审计丢失或执行后报错 |
| P2 | 初次状态目录或会话文件权限不够严格；会话断写后无法恢复，写失败仍更新内存 | `core.py`、`agent/session.py`、输出和记忆：0700/0600；恢复不完整尾行，持久化成功后更新内存 | 敏感输出暴露或会话记录不一致 |
| P2 | 工具参数 JSON 损坏被替换成空对象；中断会话留下没有结果的调用 | `agent/loop.py`：明确返回参数错误，补中断结果并要求先核实状态 | 错误调用或重复变更 |
| P2 | 日程含 NaN、损坏时间或负间隔可使 daemon 崩溃或反复运行；每日任务以 86400 秒推进产生夏令时漂移 | `agent/schedule.py`：校验时间、停用坏任务、按本地日历推进，锁错误不再静默失效 | 巡检停止、失控调用或时间偏移 |
| P2 | 多会话目标更新互相覆盖或重用续跑预算；`/goal resume` 不立即续跑，Ctrl-C 未暂停目标 | `agent/goal.py`、REPL：锁定读改写、验证预算、恢复即执行、中断暂停；坏目标不会让 Ctrl-C 处理退出 | 丢目标、额外运行或 REPL 退出 |
| P2 | 记忆首次并发写重复文件头，首次写权限有窗口；定时任务未加载已有记忆 | `agent/memory.py`、调度 system prompt：锁保护、写前收紧权限、为巡检注入记忆 | 记忆混乱或反复排查已知事实 |
| P2 | 分页 read 先读取整个文件或无上限整行；8 MB 单行只返回 30 KB 却分配约 16 MB | `agent/tools.py`：有界 readline，分块跳过长行；8 MB 回归读取峰值小于 1 MB | 大日志读取耗尽内存 |
| P2 | 实际命令退出 3 被误报“快照失败已中止”；快照拒绝原因只写 stderr | 工具统一报告非零退出，执行核心同时返回阶段原因；保留原退出码 | 用户误以为未执行并重试 |
| P2 | Markdown 忽略 NO_COLOR；非 TTY 流仍反复发终端重绘指令 | Markdown 和 REPL：统一禁色，非 TTY 只追加增量 | 重定向输出含控制码和重复内容 |
| P2 | CLI 裸 `--snapshot-cmd` 被解析成空命令，`audit --tail 0` 返回全部记录，坏配置或坏注册表不能清晰降级 | CLI 支持裸命令及 `name::command`；tail 边界校验；配置拒绝错误，损坏目标注册表保留其他状态展示 | 快照不可用、意外大量输出或状态被隐藏 |
