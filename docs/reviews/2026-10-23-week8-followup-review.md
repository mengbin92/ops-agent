## 确认问题与修复

| 优先级 | 可复现问题 | 修复结果 |
| --- | --- | --- |
| P1 | `KeyboardInterrupt/SystemExit` 不在 Exception 分支内，留下含原始秘密的半份备份/恢复 | 覆盖可捕获中断，清理前核对新建目录 inode；目录被替换时不误删替代目录 |
| P1 | 仅有 state.tar 的半成品未受保护，恢复标记也在原始文件写完后才出现 | 部分备份也受读取限制；恢复在提取前建立标记，仍校验归档里同名原始条目，支持再次备份恢复 |
| P1 | `abspath` 先抹去 `symlink/..`，绕过拒绝链接约定并把错误路径映射到别处 | 先校验原始路径组件，再规范化；保留 macOS 固定系统别名兼容 |
| P1 | active 长目标原样恢复，重新进入会话可能自动续跑 | 恢复为 paused，保留轮次预算，必须显式恢复 |
| P1 | 无效执行/调度记录、通知或目标配置恢复后才被实际 loader 拒绝 | 使用实际记录 loader 和配置约束，拒绝非法目录形状、缺字段、重复任务 ID、歧义或无效编码 JSON；失败保留源状态/归档 |
| P2 | FIFO 类型的 manifest/state.tar 在 fstat 前阻塞；异常 fstat 泄露 fd | 非阻塞打开后拒绝特殊类型，异常路径关闭 fd |
| P2 | 超大 PAX 头可触发巨大读取，tar 结束块后的内容被默认解析器忽略 | 限制底层读取请求并流式校验文件，拒绝隐藏附加数据和截断结束块；保留正常大文件/Unicode/长路径兼容 |
| P2 | manifest/恢复 JSON 的深递归、超长整数、重复键或孤立 surrogate 造成资源失控或 CLI traceback | 有界读取、整数转换前限长、严格 JSON/UTF-8、无敏感值的受控错误 |
| P2 | 清单条目数限制在全量物化目录后才检查，深路径父目录验证重复遍历 | 枚举时执行限额，逐个验证直接父目录，避免先耗尽资源再拒绝 |
| P2 | 再次恢复覆盖上一轮 recovery.json，安全字段更新也不是原子替换 | 隔离保留旧恢复证据，恢复 JSON 改为私有临时文件原子替换 |
| P1 | 演练只要求 worker 返回非空 checks，一项伪造 passed 或缺失检查也能通过 | 固定 10 项唯一检查身份，验证状态、证据结构及完成退出码；无效输出记 failed |
| P1 | 只在结束时取脚本摘要，无法确认执行期间代码和策略未变化 | parent/worker 绑定参与演练的代码与策略摘要，结束时复核；中途变化拒绝通过 |
| P1 | 继承环境可经 shell/Python 启动钩子、PATH、代理或隐藏 helper 入口突破演练隔离 | 最小环境、私有 HOME/TMP、Python -I/-B、私有会话校验、回环探针拒绝重定向和代理 |
| P1 | 父 CLI 收到 SIGTERM 时不能完整回收 worker/HTTP；强杀 worker 也跳过共享 shell 的清理 | SIGTERM 转为可清理的退出，先让 worker 执行 finally，再清理继承进程组；真实进程回归验证端口关闭和临时状态删除 |
| P2 | worker 输出无界捕获，错误片段可能被原样导出；证据输出可覆盖源代码或活动状态 | 临时文件捕获并限长，错误不复述任意 worker 内容；输出路径保护代码与活动状态，仓库内仅允许 docs/validation 的 JSON |
