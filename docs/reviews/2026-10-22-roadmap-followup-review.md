## 安全执行与恢复

| 优先级 | 复现问题 | 修复结果 |
| --- | --- | --- |
| P1 | SSH 恢复失去确认、记录为 unknown 后，再次确认可直接重放同一恢复 | 本地/远程回滚在取锁前和锁内共用 unknown 门禁；损坏执行记录同样拒绝，核实后才可恢复 |
| P1 | 本地 shell 被信号终止被记为 failed，子进程结果未核实也能再跑 | 负退出码记 unknown，并阻止重放；本地超时已终止整个进程组的原有 failed 语义保留 |
| P1 | K8s 注解、文件名、`--` 后字符串中的 `--context` 可冒充实际作用域 | 从真实 argv 提取 context/namespace，跳过选项值和分隔符后参数；无法解析的内层 shell 拒绝授权 |
| P1 | 本地原子恢复新 inode 丢失已有文件 uid/gid，配置可能变成其他账户所有 | rename 前在临时文件保留现有属主/组，权限恢复失败中止，原文件不动 |
| P1 | MCP 未预期异常 traceback、历史审计显示可泄露已知形态的凭据 | stderr/响应及审计显示统一脱敏；旧会话加载也先脱敏再复用 |
| P1 | `read` 的 offset/limit 切掉 PEM 包围标记，正文可进入模型 | 跳过前文时仍跟踪私钥块，拒绝返回块内分页片段，长行内存约束保留 |
