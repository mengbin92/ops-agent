| P1 | `git ls-remote --upload-pack=...`、`git grep -O...`、`git diff --ext-diff`、`less +!.../-o...` 可在只读入口启动程序或写日志 | 拦截 helper、初始命令、日志参数及相应长选项缩写，保留普通读取形式 |

| P1 | 工作流/inspect 的规则采集、摘要或完整报告保存失败后，模型最终回复正常可掩盖证据丢失 | 用运行上下文传递证据错误，调度在模型完成后由程序标记不完整；工具输出同步说明采集/保存失败 |
| P2 | `uname` 的 stdout 为空但 stderr 有内容时，巡检会将 stderr 当作平台并标记连通成功 | 平台只取 stdout，采集失败记 `error`；README 同步实际状态语义 |

| P2 | 深层 JSON 可让 RPC 读线程退出或使 provider/会话/工具参数处理崩溃；中等深度的未知 provider metadata 也能在递归脱敏阶段失败 | 解析与脱敏转为受控错误；RPC 后续请求仍可用；provider 仅保留支持的协议字段，会话拒绝时不写半条记录 |

| P2 | `ask_user` 回调返回约定允许的 `None` 时，loop 对结果切片崩溃，并持久化无效工具内容 | 转为明确的“用户未回答，视为拒绝”文本 |
| P2 | 快照元数据中的 `env` 为列表等非法类型时，回滚流程出现非受控异常 | 在快照 loader 中按元数据损坏拒绝 |
| P2 | 单发 CLI 遇到不可用状态目录或会话初始化失败时输出 traceback | 初始化纳入错误处理，返回 1 并输出脱敏错误 |

## 兼容行为

动态 shell 参数（如 `$HOME`、`${...}`）现在需要审批；已确认路径可直接使用绝对路径。
单引号或反斜杠保护的美元符号字面量、常规路径通配与普通只读命令继续支持。
远程内容读取的未引用 glob、内容读取的 brace 文件名展开需改为明确文件路径；本机日志 glob
会逐项复核，不能夹带敏感文件。`ls`/`find` 的普通路径通配及引用的 grep 正则保留。
旧会话中缺少关联字段的工具结果保留展示兼容，但明确畸形的调用结构会被拒绝。
审批次数、SSH 未知结果防重放、确认回滚、备份原始字节和恢复默认停用自动执行的约定保持一致。
